# Frontend Job Portal Project

This is my frontend internship project—a responsive Job Portal web application. I built this using HTML, CSS, and Vanilla JavaScript to practice building clean user interfaces, dynamic search filters, and form validations.

## 🛠️ Project Structure

Here is how the project files are organized:

*   **HTML Pages:**
    *   `index.html` - The main homepage where users can view and search for jobs.
    *   `signin.html` & `signup.html` - Forms for user login and registration.
    *   `forgot-password.html` - The password recovery layout.
    *   `404.html` - A custom page for missing links.
*   **CSS (`/css`):**
    *   `style.css` - Holds all the styling, layout, colors, and responsive design for mobile screens.
*   **JavaScript (`/js`):**
    *   `navbar.js` - Handles the mobile navigation menu toggle.
    *   `jobs.js` - Contains the mock job data used to populate the cards.
    *   `home.js` - Handles the job search filters and dynamically displays the cards.
    *   `signin.js`, `signup.js`, `forgot.js`, `helpers.js` - Manage the forms and make sure user inputs are valid.

## 🚀 Technologies Used
*   **HTML5** for page structure
*   **CSS3** (Flexbox & Grid) for styling and making it mobile-friendly
*   **JavaScript (ES6)** for interactive elements, searching, and form validation

## 💡 What I Learned During This Project
*   **Working with Git:** I learned how to track changes, handle branches, and push code to GitHub. I even learned how to debug repository configuration file errors manually when my local Git commands got stuck!
*   **DOM Manipulation:** I practiced using JavaScript to dynamically generate HTML elements (like the job cards) based on what the user types in the search bar.
*   **Folder Organization:** I learned how important it is to break code into separate modular CSS and JS files instead of putting everything into one massive file.
